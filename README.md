# Hack for Humanity Adelaide: starter files and data

Starter files and open data for **Hack for Humanity Adelaide**, a Hacktoberfest Hack Day with
MLH on Friday 30 October 2026.

This repo is not your project. On the day, your team makes its own repo, then copies in what it
needs from here.

**Too technical?** Give your AI assistant the link to this repo, or to any file in it, and ask it to
walk you through it.

## What is in here

| Folder | What it holds |
| --- | --- |
| [`starter/`](starter/) | Files for your own repo: a README template, the MIT `LICENSE`, a `.gitignore`, and a short script for your first Gemma call |
| [`data/`](data/) | Open data about South Australia, by theme, with a guide to each dataset, its source and its licence |
| [`worked-example/`](worked-example/) | An app we built to test Track 3. Learn from it, but do not submit it or copy its code |

## Download

- **Everything:** click the green **Code** button, then **Download ZIP**. The data makes this a
  big download (over 300 MB).
- **One file:** open it, then click the download icon.

  Copy them into your project freely.
- **Each dataset keeps its publisher's licence.** Most are Creative Commons Attribution (CC BY).

## Credit the data

If your project uses a dataset from here, put its credit line in your README and on your final
slide. The credit line for each dataset is in the [data guide](data/README.md), under "Credit the
source".
