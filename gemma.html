Gemma how-to

Gemma 4 is Google's open-weight model. You can use it two ways:

  • Through the Gemini API (hosted, free key, nothing to install).
  • Locally with Ollama (offline, unlimited, needs a decent laptop and a multi-gigabyte download before you arrive). Fine for building, and your backup if the API is slow.

Which way the Gemma challenge needs: see Submit and win. How Gemma should work in your app: see Build.

Steps 1 and 2 take about 10 minutes at home. Everything to set up before the day: see Before Friday.

1. Get a free API key (3 minutes)

  1. Sign in with a Google account at aistudio.google.com and choose Create API key (direct link: aistudio.google.com/apikey).
  2. Copy the key into a file called .env in your project folder:
    GEMINI_API_KEY=paste-your-key-here
  3. Add .env to .gitignore now (the text is on the GitHub how-to).

2. First call in Python (5 minutes)

pip install google-genai python-dotenv
from dotenv import load_dotenv
from google import genai
from google.genai import types

load_dotenv()                      # reads GEMINI_API_KEY from .env
client = genai.Client()            # picks the key up from the environment

response = client.models.generate_content(
    model="gemma-4-26b-a4b-it",    # Google's suggested starting model; gemma-4-31b-it is the bigger one
    contents="In two sentences: what does a hackathon team need to know about aged care in South Australia?",
    # Gemma 4 thinks first by default (20 to 60 s); "minimal" answers in seconds
    config=types.GenerateContentConfig(thinking_config=types.ThinkingConfig(thinking_level="minimal")),
)
print(response.text)

If a model name has changed by the 30th, pick any model whose name starts with gemma-4 from the model list in AI Studio. Keep the model name in one place in your code; your README names it (see Build).

Not a Python person? The same call exists in JavaScript (@google/genai), Go and REST; the quickstart has every tab (its example code targets Gemini models; swap in a gemma-4 model name).

Both Gemma 4 models on the Gemini API also take images (not audio): see Google's page in Links.

3. Optional backup: run it locally (10 minutes plus the download)

Install Ollama from ollama.com, then:

ollama pull gemma4:e4b      # about 7 GB; the default size and the sweet spot for most laptops
ollama run gemma4:e4b "Say hello in one line"

Smaller: gemma4:e2b (about 5 GB) runs on almost anything.

Ollama serves an OpenAI-style endpoint at http://localhost:11434/v1. Google's own OpenAI-compatible endpoint lists Gemini models only, so for Gemma use the google-genai call above for hosted and the Ollama endpoint for local.

4. Put it in your code

  • Wrap the call in one function (ask(prompt, image=None)) and call that everywhere.
  • Keep prompts short and structured. Give the model the data (a row, a table, a chart description) and ask for a specific output: a checklist, a plain-English explanation, a JSON object. Low temperature (about 0.2) for factual output, higher for ideas.
  • Keep thinking minimal for a live demo, as in the code above. Without it, an answer can take a minute.
  • Cache answers during the demo, so a repeat does not call the model again.
  • Rate limits. Gemma 4 is free of charge on the Gemini API (there is no paid tier for it); rate limits apply per Google project, not per key, so a second key in the same project adds nothing. Google publishes no Gemma-specific numbers; check your project's limits in AI Studio. If you hit a limit while building, switch to Ollama and come back to the API for the demo.
